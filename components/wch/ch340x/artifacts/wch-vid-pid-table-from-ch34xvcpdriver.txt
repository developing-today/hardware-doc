evidence for which USB IDs belong to which WCH part.

Note: the CH340 family shares ONE PID across every package variant. Reading the USB
ID therefore confirms "a CH340" but does NOT by itself distinguish CH340X from
CH340E/K/C/N. See ../README.md section on how to finish the identification.
