    Zerowriter Ink v2.1 — Software Beta

    Beta

    Released: July 2026

    Requires: Zerowriter Ink

    This is a beta release intended for early adopters to help test, troubleshoot, and build. 

    Download (unzip this file):

    firmware 2.1

    What's New in v2.1:

    • Stronger SD Card Engine — Now works with any Micro SD Card without filesize limitations or formatting headaches. Plus: greater reliability, stronger filesaves, and plenty of under-the-hood file improvements.
    • Improved Keyboard Accuracy — Use the built-in "debounce" option to control your keyboard sensitivity. +20MS is the reccomended setting if you find you have key ghosting or typos.
    • Easy Accent Input — Turn on the accent picker, and easily add accented characters to your work. Simply press alt and the base character, and tap the letter until you get to the accent you need.
    • Built-in Internal Storage — SD Card-first saves, with an automatic fall-back to internal storage (now accessible, clear, and called HD). 
    • Auto-Backup Saves — Turn on to mirror every save to HD.  This makes every save happen in two places, automatically, meaning your writing is twice as safe.
    • Menu Redesign — Modernized menu with more organization and options. Simpler navigation. 
    • Writing Stats — New Stats menu with long-term tracking and trends. Tracks words written, time spent, streaks, and more. Requires a coin cell installed for all timekeeping features.
    • Improved Markdown & Fountain — Bold, italic, strikethrough, inline code spans, blockquotes, fenced code blocks, and lists. Fountain bug fixes and improvements. Renders inline as you type.
    • Status Bar Redesign — Cleaner, more flexible, and less in the way. Toggle through status bars with CTRL+TAB.
    • Word Count Autosave — Autosave now uses wordcount instead of returns.
    • Battery Accuracy — Improved battery sensor accuracy.
    • Privacy Render Mode — Masks non-active body lines with glyphs. Useful for writing something steamy in public.
    • And more!

    Installation Instructions

    1. Download the .zip file above, and unzip it to find the firmware.bin file.
    2. Ensure the file is named exactly: firmware.bin
    3. Copy the file to the root of your SD card (not in a folder)
    4. Safely eject the SD card from your computer
    5. Insert the SD card into your Zerowriter Ink
    6. Power up or restart your Zerowriter Ink
    7. Wait for the update to complete
    8. Device will restart automatically
    Web Updater Method (Advanced)

    Consider this method if the SD card update fails:

    1. Visit the Web Updater
    2. After completing the Web Updater manual update, you can then update using the 2.1 software instructions above.
