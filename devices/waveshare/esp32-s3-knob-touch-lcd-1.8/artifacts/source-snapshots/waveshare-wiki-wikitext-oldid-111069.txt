== Introduction ==
The ESP32-S3-Knob-Touch-LCD-1.8 is a high-performance, highly integrated microcontroller development board designed by Waveshare, featuring dual MCU control with ESP32-S3 and ESP32, integrated large capacity Flash and PSRAM, and a built-in 1.8inch LCD screen. It includes highly integrated audio decoding chip, rotary encoder, and other peripherals, enabling rapid development of intelligent voice AI applications.

== Features ==
*Equipped with dual MCUs (ESP32-S3 and ESP32), featuring up to 4 cores and a clock frequency up to 240 MHz
*Supports 2.4 GHz Wi-Fi (802.11 b/g/n), Bluetooth 5 (BLE) and Classic Bluetooth, with onboard antenna
*Built-in 512KB SRAM, 384KB ROM, 16MB Flash and 8MB PSRAM
*Controls the touchscreen through the I2C interface, supporting interrupt output
*Onboard audio decoding chip, microphone (MIC), rotary encoder, vibration motor, TF card slot, and battery charging management module
*CNC precision-machined housing with aesthetic structure, sturdy and durable, and easy to carry

*Download in advance the [[#AIDA64 Configuration File|AIDA64 Configuration File]] we provided

2. Click File -> Preferences -> LCD, then select RemoteSensor, as shown below:<br/>
[[File:1500px-ESP32-S3-Knob-Touch-LCD-1.8-29.png|1000px]]<br/>
3. Click the LCD Items, select to import the AIDA64 configuration file downloaded in advance, as shown in the image:<br/>
[[File:1500px-ESP32-S3-Knob-Touch-LCD-1.8-30.png|1000px]]<br/>
 1. Click Import to import configuration file
 2. There are 8 parameters in total. Everyone's computer configuration is different, so this needs to be configured according to actual conditions. Double-click to edit
 3. Double-click to edit, Show label cannot be modified, Show unit must be filled with "^", otherwise the system will not recognize it
4. After setting up, minimize AIDA64 or set it to start on boot. Next, configure the screen parameters, as shown in the image:<br/>
[[File:ESP32-S3-Knob-Touch-LCD-1.8-6.png|2400px]]<br/>
 1. If the IP address is not displayed, you can use your phone to connect to WIFI: My Ap, password: 12345678
 2. After the connection is successful, open the browser and enter 192.168.4.1 to configure the mobile phone network
 3. After the network configuration is successful, the IP address will be displayed as shown in Figure 4
 4. It is important to note that the AP must be on the same LAN as the computer.
5. In the browser, enter the new acquired IP address for the screen. Scroll down to the PC Monitor section and input the IP address where AIDA64 is running, as shown in the image:<br/>
[[File:ESP32-S3-Knob-Touch-LCD-1.8-31.png|1000px]]<br/>
 1. If port 80 of the computer is already occupied, you need to add the port number
 2. Click Save
6. Then go back to the secondary screen interface, you can see that some parameters of the computer have been displayed on the screen, as shown in the figure:<br/>
[[File:ESP32-S3-Knob-Touch-LCD-1.8-33.png|600px]]<br/>
 If the display fails, it's worth checking if the computer firewall is restricting it. If it's due to the firewall, the simplest way is to disable the firewall for testing purposes

=BIN File Flashing=
<div class="mw-collapsible-content">
*Download the BIN files we provided under [[#BIN File | BIN File]] in advance. Below, an example will be given for the Windows system; other systems are similar<br/>
1. Extract the downloaded BIN file compressed file, press and hold WIN+R ->enter CMD and enter Enter to enter the command line, and then check whether the system has Python and pip (most computers will have), as shown in the figure:<br/>
[[File:ESP32-S3-Knob-Touch-LCD-1.8-22.png|1000px]]<br/>
 You can see that the Python version is 3.11.9 and the pip version is 24.0
 If there are no corresponding versions, you can visit the Python official website to install Python first. After installation is successful, install pip using the command line
<pre>
curl https://bootstrap.pypa.io/<nowiki>get-pip.py</nowiki> <nowiki>-o</nowiki> <nowiki>get-pip.py</nowiki>
</pre>
2. Install the esptool tool as shown in the figure:<br/>
[[File:ESP32-S3-Knob-Touch-LCD-1.8-23.png|1000px]]<br/>
 Enter the command above to install esptool
 You can see that the system already has ESPTOOL version 24.0
3. Check the path of the esptool tool, as shown in the figure:<br/>
[[File:ESP32-S3-Knob-Touch-LCD-1.8-24.png|1000px]]<br/>
 Enter the command above to view the original path of esptool
4. Add the path to the user environment variable, and then reopen the command line, as shown in the figure:<br/>
[[File:ESP32-S3-Knob-Touch-LCD-1.8-25.png|1000px]]<br/>
5. The board has two MCUs, ESP32 and ESP32-S3. We first identify which board the COMx connected to the computer is, as shown in the figure:<br/>
[[File:ESP32-S3-Knob-Touch-LCD-1.8-50.png|1000px]]
 1. Enter the command : esptool.exe --port COMx --baud 115200 chip_id
 2. COMx refers to the COM after the device is connected to the computer, which can be checked through the Device Manager
 3. Confirm that it is ESP32 or ESP32S3, you can check the chip type
6. The board has two MCUs onboard, namely ESP32 and ESP32S3. First, flash the bin file to the ESP32, as shown in the image:<br/>
[[File:ESP32-S3-Knob-Touch-LCD-1.8-26.png|1000px]]<br/>
 1. --chip esp32: Indicates the chip type, such as ESP32, ESP32S3, ESP32C6, etc.
 2. --port: Indicates the serial port, which can be checked in the Device Manager -> Ports to see the corresponding COMx
 3. --baud: Baud rate
 4. write_flash: Flashing command
 5. -z: Enables compression
 6. 0x0: Flashing address
 7. .bin: Indicates the firmware path, which is the path of the firmware after decompression
 If the flashing fails, check whether the chip type and COMx are incorrect, reconfirm and execute the flashing command
7. Next, flash the ESP32-S3 bin file, as shown in the figure:<br/>
[[File:ESP32-S3-Knob-Touch-LCD-1.8-27.png|1000px]]<br/>
 1. Note that it needs to be changed to ESP32S3
 2. COM also needs to be modified to the corresponding one
 3. Be careful not to select the wrong BIN file
 If the flashing fails, check whether the chip type and COMx are incorrect, reconfirm and execute the flashing command
8. After flashing is complete, toggle the switch to reboot the device, as shown in the image:<br/>
[[File:675px-ESP32-S3-Knob-Touch-LCD-1.8-21.png|450px]]<br/>

{{FAQ| Why can't the program be flashed?|
This product features two onboard chips, ESP32-S3 and ESP32. The two insertion orientations of the Type-C plug connect to different download channels.

*If programming fails, the serial port is not found, or the connection cannot be established, please perform the following steps first:

**1. Disconnect the Type-C cable;
**2. Flip the Type-C plug 180°;
**3. Re-insert the cable and attempt programming again.<br>

{{FAQ| How do I check the COM port I use? |
*Windows system:
①View through Device Manager: Press the Windows + R keys to open the "Run" dialog box; input devmgmt.msc and press Enter to open the Device Manager; expand the "Ports (COM and LPT)" section, where all COM ports and their current statuses will be listed. <br>
②Use the command prompt to view: Open the Command Prompt (CMD), enter the "mode" command, which will display status information for all COM ports. <br>
③Check hardware connections: If you have already connected external devices to the COM port, the device usually occupies a port number, which can be determined by checking the connected hardware.
*Linux system:
①Use the dmesg command to view: Open the terminal. <br>
①Use the ls command to view: Enter ls /dev/ttyS* or ls /dev/ttyUSB* to list all serial port devices. <br>
③Use the setserial command to view: Enter setserial -g /dev/ttyS* to view the configuration information of all serial port devices. </br>
|||}}
