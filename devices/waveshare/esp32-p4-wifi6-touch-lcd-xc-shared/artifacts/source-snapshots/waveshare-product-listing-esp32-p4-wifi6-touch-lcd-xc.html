Features

This product is a high-performance development board based on ESP32-P4 controller with RISC-V 32-bit dual-core and single-core processors. Options for 3.4inch 800 × 800 IPS round touch display version and 4inch 720 × 720 IPS round touch display version. It features rich Human-Machine interfaces including MIPI-CSI (with integrated Image Signal Processor), and supports USB OTG 2.0 HS for high-speed communication. Onboard 40PIN GPIO header which is compatible with some Raspberry Pi HATs, enabling a wider range of application adaptability.

It also integrates the Digital Signature Peripheral and a dedicated Key Management Unit, ensuring secure data and operations. Specifically designed for high-performance and high-security applications, to meet the higher requirements of embedded applications such as Human-Machine interaction, efficient edge computing, and IO expansion.

  • High-performance MCU with RISC-V 32-bit dual-core and single-core processors
  • 128 KB HP ROM, 16 KB LP ROM, 768 KB HP L2MEM, 32 KB LP SRAM, 8 KB TCM
  • Powerful image and voice processing capability. Provides image and voice processing interfaces including JPEG Codec, Pixel Processing Accelerator, Image Signal Processor, H264 encoder
  • 32MB PSRAM in the chip's package, with onboard 32MB Nor Flash
  • Commonly used peripherals such as MIPI-CSI, MIPI-DSI, USB 2.0 OTG HS, SDIO 3.0 TF card slot, dual microphones (support echo cancellation), speaker header and RTC battery header, etc.
  • Onboard 2*20 GPIO header with 28 x remaining programmable GPIOs
  • Security features: Secure Boot, Flash Encryption, cryptographic accelerators, and TRNG. Additionally, hardware access protection mechanisms help to enable Access Permission Management and Privilege Separation

What's On Board
  1. ESP32-P4-Core
    Integrated ESP32-P4NRW32, 32MB Nor Flash
  2. ESP32-C6-MINI-1 module
    SDIO interface protocol, extending Wi-Fi 6 / Bluetooth 5 (LE)
  3. MIPI CSI interface
    15Pin pitch 1.0mm connector, for connecting MIPI 2-lane cameras
  4. ES7210 echo cancellation chip
    Echo cancellation algorithm chip, used to eliminate echo and improve audio capture accuracy
  5. Type-C connector
    USB 2.0 Full Speed interface, for power supply, program burning, and debugging
  6. RTC battery header
    for connecting rechargeable RTC battery (supports rechargeable RTC batteries only)
  7. USB TO UART Type-C connector
    for power supply, program burning and debugging
  8. Power LED indicator
  9. USB OTG Type-A connector
    USB OTG 2.0 High-Speed interface
  1. ES8311 low-power audio codec chip
    for audio encoding and decoding
  2. Speaker header
    PH 2.0 2P connector, supports 8Ω 2W speaker (recommended)
  3. Onboard microphones
    Microphone inputs with echo cancellation
  4. MIPI DSI LCD interface
    for connecting MIPI 2-lane LCD screens
  5. ESP32-C6 UART header
    SH1.0 4Pin connector, for ESP32-C6 module firmware burning
  6. ESP32-P4 I2C header
    SH1.0 4Pin connector, for connecting external I2C devices
  7. 40PIN GPIO header
    pitch 2.54mm, compatible with some Raspberry Pi HATs (a pinheader adapter is required)
  8. BOOT button
    Press it when powering on or resetting to enter download mode
  9. TF card solt
    SDIO 3.0 interface protocol
  10. RESET button
